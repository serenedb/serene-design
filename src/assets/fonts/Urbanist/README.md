# Urbanist

Licensed under SIL OFL 1.1; see OFL.txt in this directory.

These complete Latin and Latin-extended variable fonts were downloaded from
Google Fonts and converted from TTF to WOFF2 with fontTools, without subsetting
or changing outlines. Both faces have a weight axis from 100 to 900.

Sources:
- https://github.com/google/fonts/blob/main/ofl/urbanist/Urbanist%5Bwght%5D.ttf
- https://github.com/google/fonts/blob/main/ofl/urbanist/Urbanist-Italic%5Bwght%5D.ttf
- https://github.com/google/fonts/blob/main/ofl/urbanist/OFL.txt
